## 🛠️ 기술 스택 및 개발 규칙
* **사용 언어:** 순수 HTML5, CSS3 (JavaScript 및 외부 프레임워크 미사용)
* **배포 방식:** GitHub Pages
* **협업 규칙:**
  1. 각자 개인 브랜치(`main` 외 개별 브랜치)에서 작업 후 Pull Request(PR)를 통해 코드 리뷰 및 병합 진행
  2. 공통 스타일(`style.css`) 수정 시 사전 공유 필수
  3. 시맨틱 태그 및 CSS 여백(`margin`, `padding`) 활용 준수
